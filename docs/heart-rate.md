# Heart rate

If your console reports heart rate (hand grips or a built-in receiver), Fellwater
shows and records it. If not, pair any standard Bluetooth LE chest strap:

1. Put the strap on, so it wakes up.
2. **Setup → Heart-rate strap → Find strap**, then tap it.

Heart rate then appears next to the other numbers, is saved with each row and is
included in TCX exports. The strap reconnects by itself whenever it is back in range,
including on later launches. **Forget strap** unpairs it.

The strap is only used when the rower itself sends no heart rate.
